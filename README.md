# CorpusLab ESA — camada pública sanitizada

Este repositório foi preparado para reunir a camada pública sanitizada de uma pesquisa de mestrado sobre a arquitetura formativa no Curso de Comunicações da Escola de Sargentos das Armas, tomando a preparação institucional para o ingresso de mulheres como lente analítica.

## Finalidade

A camada pública busca oferecer transparência acadêmica e auditabilidade metodológica sem expor documentos internos, instrumentos locais, dados pessoais, resultados individuais, links de acesso controlado ou informações cuja circulação aberta não tenha sido revisada.

## Escopo inicial

O primeiro lote contém somente:

- critérios metodológicos;
- política de publicabilidade;
- catálogo seletivo e sanitizado do corpus;
- linha do tempo seletiva;
- matriz-síntese agregada dos 23 casos analíticos;
- correspondência agregada entre Perfil, Mapa Funcional e currículo.

O manuscrito completo e o acervo granular não fazem parte deste primeiro lote.

## Regra metodológica central

A pesquisa reconstrói o que os documentos permitem afirmar sobre aquilo que a instituição prescreve, organiza, orienta, projeta, prevê, exige, observa, avalia, classifica, reconhece e legitima.

Ela não afirma, sem evidência própria, que disposições, valores, comportamentos ou identidades tenham sido efetivamente incorporados pelos sujeitos.

## Camadas de acesso

- **Camada sanitizada:** este repositório.
- **Acervo completo/controlado:** mantido separadamente, com documentos de trabalho, corpus granular, instrumentos locais e materiais cuja circulação exige controle.

## Conteúdo deliberadamente ausente

Não são disponibilizados aqui:

- cópias integrais de documentos internos não publicados oficialmente;
- instrumentos locais de avaliação ou acompanhamento;
- planilhas-fonte completas;
- bases de evidências finas;
- nomes, notas, menções, rankings ou resultados individuais;
- links para acervos privados;
- materiais operacionais sensíveis;
- versões de trabalho não estabilizadas.
